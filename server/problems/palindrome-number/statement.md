Given an integer `x`, return `true` if `x` is a palindrome, and `false` otherwise.

**Constraints:**

- `-2^31 <= x <= 2^31 - 1`

**Example 1:**

> **Input:** x = 121
> **Output:** true

**Example 2:**

> **Input:** x = -121
> **Output:** false
> **Explanation:** Reads -121 from left to right and 121- from right to left, so it is not a palindrome.

**Example 3:**

> **Input:** x = 10
> **Output:** false
