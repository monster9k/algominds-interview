# AlgoMinds — server

NestJS 11 backend for AlgoMinds. See the [root README](../README.md) for full setup (Docker infra, `.env`, Prisma, seed data) and [`CLAUDE.md`](../CLAUDE.md) for architecture (module layout, session lifecycle, data model).

## Quick reference

```bash
npm install
npx prisma generate
npm run start:dev
```

```bash
npm run build
npm run start:prod
npm run lint
npm run format
npm run test
npm run test:e2e
```
