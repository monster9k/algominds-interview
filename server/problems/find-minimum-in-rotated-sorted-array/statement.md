Suppose an array of unique integers, sorted in ascending order, is rotated between `1` and `n` times. Given the rotated array `nums`, return the minimum element of this array. You must write an algorithm that runs in `O(log n)` time.

**Constraints:**

- `n == nums.length`
- `1 <= n <= 5000`
- All the integers of `nums` are unique.
- `nums` is sorted and rotated between `1` and `n` times.

**Example 1:**

> **Input:** nums = [3,4,5,1,2]
> **Output:** 1

**Example 2:**

> **Input:** nums = [4,5,6,7,0,1,2]
> **Output:** 0

**Example 3:**

> **Input:** nums = [11,13,15,17]
> **Output:** 11
