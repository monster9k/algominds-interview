Given an integer array `nums` sorted in non-decreasing order, return the number of unique elements in `nums`.

**Constraints:**

- `1 <= nums.length <= 3 * 10^4`
- `-100 <= nums[i] <= 100`
- `nums` is sorted in non-decreasing order.

**Example 1:**

> **Input:** nums = [1,1,2]
> **Output:** 2
> **Explanation:** The unique values are 1 and 2.

**Example 2:**

> **Input:** nums = [0,0,1,1,1,2,2,3,3,4]
> **Output:** 5
> **Explanation:** The unique values are 0, 1, 2, 3, and 4.

**Example 3:**

> **Input:** nums = [1,1,1]
> **Output:** 1
