You are given a large integer represented as an integer array `digits`, where each `digits[i]` is the `i`-th digit of the integer, ordered from most significant to least significant. Increment the large integer by one and return the resulting array of digits.

**Constraints:**

- `1 <= digits.length <= 100`
- `0 <= digits[i] <= 9`
- `digits` does not contain any leading `0`'s, except the number `0` itself.

**Example 1:**

> **Input:** digits = [1,2,3]
> **Output:** [1,2,4]

**Example 2:**

> **Input:** digits = [4,3,2,1]
> **Output:** [4,3,2,2]

**Example 3:**

> **Input:** digits = [9]
> **Output:** [1,0]
